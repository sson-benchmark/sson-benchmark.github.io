# SSoN project website

Project website for **Same Space or Not (SSoN)**, a benchmark for spatial intelligence through cross-view contradictions and part of the **AI Vision Exam** series.

[Homepage](https://sson-benchmark.github.io/) · [Code](https://github.com/sson-benchmark/SSoN) · [Dataset](https://huggingface.co/datasets/HuiziCao/SSoN) · [Checkpoints](https://huggingface.co/HuiziCao/SSoN-Qwen2.5-VL-7B-LoRA)

**Paper (arXiv):** Coming soon.

## About

SSoN asks whether four images can depict the same unchanged 3D scene. Three views are mutually consistent; one contains a contradiction. The task is to identify the inconsistent view and explain the contradiction using evidence across views.

The project website presents interactive examples, the benchmark construction framework, and evaluation results. Experiment code is available in the [SSoN repository](https://github.com/sson-benchmark/SSoN).
